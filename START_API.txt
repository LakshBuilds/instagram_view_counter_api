========================================
HOW TO START THE API SERVER
========================================

In PowerShell, you MUST use .\ prefix:

CORRECT:
  .\restart_api.ps1
  .\restart_api.bat

WRONG:
  restart_api.bat
  restart_api.ps1

========================================
QUICK COMMANDS:
========================================

PowerShell Script:
  .\restart_api.ps1

Batch File:
  .\restart_api.bat

Manual Start:
  python api.py

========================================
WHY .\ IS NEEDED:
========================================

PowerShell doesn't run scripts from current directory
by default for security. The .\ tells PowerShell to
look in the current directory.
